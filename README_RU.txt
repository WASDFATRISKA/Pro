BODY EVOLUTION — PWA
=====================

Что это:
- Устанавливаемый веб-трекер для Android/Samsung.
- Тёмный интерфейс.
- Вес, история измерений, тренировки, фото прогресса.
- Локальное хранение в браузере (localStorage).
- Экспорт/импорт JSON.
- Service Worker для офлайн-работы после первой загрузки.

ВАЖНО:
PWA нельзя полноценно установить, открыв index.html как обычный файл.
Для установки нужен HTTPS-хостинг (или localhost для тестирования).
Проще всего развернуть папку на статическом хостинге:
1. Создай репозиторий GitHub и загрузи в него все файлы из архива.
2. В GitHub открой Settings → Pages.
3. В разделе Build and deployment выбери Deploy from a branch.
4. Выбери ветку main и папку /(root), нажми Save.
5. Дождись публикации сайта. GitHub покажет HTTPS-ссылку.

УСТАНОВКА НА SAMSUNG:
1. Открой опубликованную HTTPS-ссылку в Google Chrome на телефоне.
2. Нажми ⋮ → Установить приложение (или Добавить на главный экран).
3. Подтверди установку. Иконка появится среди приложений.
4. Открой Body Evolution. После первой загрузки приложение сможет работать офлайн.

ЛОКАЛЬНЫЕ ДАННЫЕ:
- Данные хранятся в браузере этого устройства.
- Не очищай данные Chrome/сайта, иначе записи могут пропасть.
- Регулярно открывай вкладку «Данные» → «Экспортировать JSON».
- Фото хранятся в локальном хранилище браузера и не попадают в JSON-экспорт.
  Сохраняй оригиналы фото отдельно.
- При импорте JSON текущие записи заменяются импортированными.
